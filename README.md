<h1>Below The Blue</h1>

<p>A 2-player co-op submarine game built in <b>Unity</b>, played on a <b>physical arcade console</b> powered by an <b>Arduino Uno</b>. Made as the final project of the <b>MAT102</b> course at <b>KMUTT</b>.</p>
