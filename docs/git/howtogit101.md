<h2>Part 1: Setup (only once)</h2>

<h3>1. Install GitHub Desktop</h3>
<p><a href="https://central.github.com/deployments/desktop/desktop/latest/win32">Click here to download</a></p>

<h3>2. Sign in</h3>
<p>Open GitHub Desktop → <b>Sign in to GitHub.com</b>. Your browser opens; log in and click <b>Authorize</b>.</p>

<h3>3. Download (clone) the project</h3>
<ol>
  <li>Go to <a href="https://github.com/PaleHazeGuy/BelowTheBlue_MAT102">the project page</a></li>
  <li>Click the green <b>&lt;&gt; Code</b> button</li>
  <li>Click <b>Open with GitHub Desktop</b></li>
  <li>If your browser asks to open GitHub Desktop, click <b>Open</b> / <b>Allow</b></li>
  <li>GitHub Desktop opens with everything filled in. Leave the location as default (<code>Documents\GitHub\BelowTheBlue_MAT102</code>)</li>
  <li>Click <b>Clone</b></li>
</ol>

<p>✅ The project is now on your computer, in your <b>Documents</b> folder.</p>
